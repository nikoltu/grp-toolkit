2 · Tools
🎯Wireframe tester
Unit wireframe color model (HP/shield, per-part gradient), SD indices + HD masks, heatmap. Export → wireframe-colors.json.
requires an open MPQ / CASC
🧠Campaign analyzer
All campaign missions auto-listed (no manual hierarchy): 🎙 briefing timeline (who speaks/portrait/wav/duration), 🎯 unit actions from triggers (Move/Patrol/Attack), AI scripts + scaler.
requires an open MPQ (BW)
🖥️HUD editor
HUD v2 panel layout (drag+resize, lock, undo/redo) → hud2_* C++ formulas + JSON.
works without data
🤖Bot builder
Tactics table (build order + adaptation branches) → byte-exact aiscript.bin. Templates: rush / defense / adaptive. Merge into stock or standalone.
works without data
📊DAT editor
units.dat / weapons.dat: HP (1/256), shield, armor, cost, build-time, damage. Field layout confirmed by 4 anchors. → data/arr/… override.
requires an open MPQ / CASC
🎨Sprite importer
PNG frames → palette quantization → classic GRP (pixel round-trip oracle) → data/unit/… override. SD unit reskin without C++.
works without data
🎞️iscript viewer
Animation bytecode disasm (iscript.bin): playfram/wait/goto/imgol/playsnd. 398 scripts, 9763 opcodes, 0 desync (coverage oracle).
requires an open MPQ / CASC
📦Mod Builder
Packs editor outputs into a launcher .zip mod (scaled aiscript.bin + file overrides). JS AI assembler + zip.
works without data
3 · Preview (open a file in the tree on the left)
🖼️Graphics
.grp (RLE+flat), .dds.grp, .anim, .pcx — rendered; export a classic GRP as .grpi.
🎬Video + audio
.smk own decoder (519/519), .webm natively + frame export, .wav/.ogg with waveform (Huffman+ADPCM from MPQ).
🤖AI scripts
Open aiscript.bin/bwscript.bin → disasm + semantics + scaler. 293 scripts, 0 unknown opcodes.
🎥Replay viewer
Open .rep (classic or SC:R) → build order, APM/EAPM, tech/upgrade, who left + full command log (who built/did/attacked). Python tools/rep/ twin.
works without data
🗺️Campaign missions
Automatically filters out all campaign missions from the open MPQ — no need to walk the tree. For each: 🤖 bot behavior from AI scripts (build/attack) + 📖 walkthrough cross-reference + briefing + heroes.
requires BW .mpq
All decoders have byte-for-byte oracles — see tests/.
