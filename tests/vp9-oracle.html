VP9 keyframe decoder vs. libvpx

Compares tools/vp9_pixels.py (stage 3b) against this browser's own VP9 decoder through WebCodecs, plane for plane in the codec's native buffer (I420 for 4:2:0, I444 for 4:4:4) — never RGB, so nothing is measured except the decode. Only loop_filter_level == 0 frames are compared, because the loop filter is a later stage; libvpx's filter is a no-op on them.

Run py tests/test_vp9_pixels.py --export, then serve the repo root (py tests/_serve.py) and open this page.
