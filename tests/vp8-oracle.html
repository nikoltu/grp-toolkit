VP8 keyframe decoder vs. libvpx

Compares tools/vp8_decode.py's output against this browser's own VP8 decoder through WebCodecs, plane for plane in I420 — the codec's native colour space, so nothing is measured except the decode itself.

The whole VP8 keyframe corpus is here — 633 frames, 490 of them loop-filtered (stage d). The Python side hashes its own I420 into manifest.json; this page decodes each keyframe with libvpx, hashes the result the same way, and compares digests. Everything ships in a single keyframes.bin fetch, because the preview proxy drops per-file requests under load.

Run py tests/test_vp8_pixels.py --export first, then serve the repo root (py tests/_serve.py) and open this page.
