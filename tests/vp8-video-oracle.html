VP8 inter-frame decoder vs. libvpx

Decodes every frame of every exported clip through this browser's libvpx (WebCodecs), plane for plane in I420, and compares each frame to tools/vp8_decode.py's output via SHA-256. This exercises the inter path — motion compensation, reference frames, the 6-tap filter — over whole sequences, where a drift shows up within a few frames.

Run py tests/test_vp8_video.py --export first, then serve the repo root (py tests/_serve.py) and open this page.
